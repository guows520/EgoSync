# 2. 管家、角色与工作区

## 2.1 管家视图和角色视图

### 管家视图

管家是全局入口，适合：

- 描述跨领域目标；
- 让系统判断应该由哪个角色处理；
- 查看所有角色的任务、活动和状态；
- 接收主动建议、提醒、晨间简报和周复盘；
- 处理角色之间的时间冲突。

![[1.5.1.png]]

### 角色视图

角色视图只聚焦一个领域，适合：

- 与角色进行连续对话；
- 查看该角色的任务和记忆；
- 编辑角色目标、个性和主动性；
- 为角色绑定 Skill 和 MCP Server；
- 管理角色的归档或删除。

![[1.4.3.png]]

## 2.2 添加角色

1. 点击左侧导航栏的“添加角色”。
2. 填写“角色名称”。
3. 填写“目标”（可选，但建议填写）。
4. 选择图标和颜色。
5. 点击“创建角色”。

创建后，角色会出现在左侧角色导航中。

### 角色名称建议

- 使用清晰、短的领域名称：岗位名称、家庭角色、健康管理、学习管理。
- 如果角色承担的是具体职责，可使用职责名称：研究助理、项目教练、财务顾问。
- 不建议把多个完全不同的领域放入同一个角色，否则任务和记忆会混在一起。

## 2.3 编辑角色信息

进入角色后，打开工作区的“设置”标签：

1. 在“角色信息”中修改名称。
2. 重新选择图标或颜色。
3. 修改角色目标。
4. 在“角色个性描述”中说明语气、判断方式和表达习惯。
5. 点击“保存角色信息”。

## 2.4 主动性刻度盘

角色设置中可以调整主动性级别。级别越高，角色越可能在工作循环中主动提出建议；级别越低，角色越倾向于等待你发起对话。

建议按以下方式选择：

- **低**：只希望角色在你询问时回应。
- **中**：接受必要提醒和周期性建议。
- **高**：希望角色主动发现风险、提醒任务和推动计划。

主动性不会替你直接执行高风险操作。需要执行的建议通常会先以建议卡片或通知形式出现，等待你确认。

## 2.6 工作区标签

管家和角色工作区通常包含以下标签：

- **仪表盘(管家专属)**：查看活动、角色状态、能量和统计。
- **任务**：创建、筛选、排序和完成任务。
- **记忆**：查看系统提炼的结构化记忆并追溯来源。
- **设置**：编辑角色或管家的行为、Skill、MCP 等配置。

点击当前已打开的标签可以收起工作区，回到更宽的对话区域。

## 2.7 管家从对话中建议创建角色

当管家持续发现某个领域有稳定需求时，可能会提出创建新角色的建议：

1. 阅读管家给出的角色名称、目标和理由。
2. 选择接受，创建角色；或拒绝，继续使用当前角色。
3. 创建后可在角色设置中继续调整。

建议不代表必须创建。只有当某个领域会持续产生独立任务和记忆时，才适合单独建角色。

## 2.8 设置页面的折叠与展开

角色设置由多个区块组成。你可以：

- 点击区块标题展开或收起内容；
- 点击“全部展开”一次查看所有设置；
- 点击“全部折叠”只保留区块标题，便于快速定位。

设置较多时，建议先全部折叠，再只打开当前要修改的区块。
