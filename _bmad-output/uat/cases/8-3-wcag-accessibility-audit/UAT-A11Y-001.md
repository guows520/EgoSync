# UAT-A11Y-001 键盘导航覆盖主要交互路径

## 业务场景
视觉障碍或行动不便的用户希望仅用键盘就能完成主要操作——Tab 键序覆盖 Sidebar → 管家对话 → 工作面板 → Modal，Enter/Space 激活按钮，Escape 关闭 Modal，所有可交互元素有可见焦点环。

## 前置条件
- 应用已启动并完成 onboarding

## 测试步骤
1. 仅用键盘（不用鼠标）操作应用
2. 用 Tab 键从 Sidebar 导航到管家对话再到工作面板
3. 用 Enter/Space 激活按钮
4. 打开 Modal 后用 Escape 关闭
5. 观察焦点环

## 预期结果
- Tab 键序覆盖 Sidebar → 管家对话 → 工作面板 → Modal
- Enter/Space 激活按钮
- Escape 关闭 Modal/确认弹窗
- 所有可交互元素有可见 :focus-visible 焦点环
- 焦点初始落点合理（Modal 打开时聚焦首个可交互元素）
