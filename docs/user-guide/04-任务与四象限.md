# 4. 任务与智能四象限

## 4.1 创建任务

任务可以从角色任务页、管家“全部任务概览”或对话中的建议创建。

1. 点击“新增任务”。
2. 选择任务归属：管家或某个角色。
3. 填写任务内容。
4. 选择四象限分类：可以选择“智能判断”，也可以手动指定。
5. 可选：设置截止日期和时间。
6. 可选：勾选“标记为本周大石头”。
7. 点击“保存任务”。

截止时间选择完成后，时间选择器会自动收起；如需修改，再次点击截止时间即可。

## 4.2 编辑、完成和删除任务

- 点击任务右侧的编辑按钮修改内容。
- 点击任务前的勾选按钮标记完成；再次点击可以撤销完成。
- 点击删除按钮移除任务。
- 拖动任务可以调整同一列表中的顺序。

删除是对任务记录的移除；如果任务来自重要计划，建议先确认是否需要保留在对话或复盘记录中。

## 4.3 理解四个象限

| 象限 | 含义 | 使用建议 |
| --- | --- | --- |
| Q1 重要且紧急 | 需要尽快处理的事情 | 明确下一步和截止时间 |
| Q2 重要但不紧急 | 对长期目标最有价值的事情 | 重点保护，提前安排时间 |
| Q3 不重要但紧急 | 需要回应，但不一定应由你亲自完成 | 尝试委派、模板化或批量处理 |
| Q4 不重要且不紧急 | 可延后、减少或删除的事情 | 控制投入，避免挤压 Q2 |

EgoSync 可以根据任务内容和上下文自动判断象限；你也可以在任务编辑时手动改分类。

## 4.4 “智能判断”什么时候最有用

适合让系统判断的情况：

- 任务描述较完整，包含目标、截止时间或影响范围；
- 你不确定任务应该放在哪个象限；
- 任务来自对话，需要快速整理。

如果任务只有“处理一下”“跟进项目”这类模糊描述，建议先补充具体结果，再使用智能判断。

## 4.5 标记本周大石头

“大石头”表示本周最重要、最值得保护的任务。标记后：

- 任务列表会突出显示“大石头”；
- 周计划和周复盘会围绕它进行回顾；
- 系统会在工作日关注它是否持续被低优先级任务挤压；
- 必要时管家会发送保护提醒。

每周建议只选择少量真正重要的“大石头”，否则重点会失去意义。

## 4.6 Q2 保护机制

Q2 任务通常重要但不紧急，最容易被临时事项挤掉。系统会记录这类任务的延期或被挤压情况，并在达到提醒条件时提示你。

收到提醒后，可以选择：

1. 立即安排一个可执行的时间块；
2. 拆成更小的下一步；
3. 调整截止时间或优先级；
4. 确认它当前确实不再重要。

不要只把 Q2 任务不断延期；如果它连续被挤压，通常说明计划容量或任务范围需要调整。

## 4.7 管家全部任务概览

在管家视图打开“任务”标签，可查看管家和所有角色的任务汇总：

- 按归属筛选管家或某个角色；
- 按四象限分组查看；
- 识别大石头、临近截止和被持续挤压的任务；
- 直接新增、编辑、完成或删除任务。

## 4.8 推荐的任务写法

不要写：

> 准备发布会

建议写：

> 在 7 月 31 日前完成发布会方案初稿，并列出需要设计和研发确认的 5 个问题

一个可执行任务通常包含：动词、结果、边界和时间。
