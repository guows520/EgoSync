# 6. 主动工作、简报与周复盘

## 6.1 主动工作循环

角色可以按调度频率运行后台工作循环，用于检查任务状态、识别风险和生成建议。主动工作不会等同于自动替你执行所有操作；重要动作通常会先形成建议，等待你确认。

主动工作是否频繁，取决于：

- 角色的主动性级别；
- 调度时间配置；
- 当前任务和截止时间；
- 是否存在大石头或 Q2 保护风险；
- 模型服务和 Agent 是否可用。

## 6.2 主动建议的处理方式

当管家或角色提出建议：

1. 先看建议内容和来源。
2. 判断它是否与当前目标相关。
3. 选择确认、拒绝或稍后处理。
4. 如果确认，检查生成的任务标题、归属、截止时间和四象限。

主动建议可以帮助你减少遗漏，但最终优先级仍由你确认。

## 6.3 三级通知

EgoSync 使用三种通知强度：

| 级别 | 适合提醒什么 | 你的处理方式 |
| --- | --- | --- |
| 耳语 | 低打扰的提示、轻量建议 | 有空时查看 |
| 轻触 | 需要注意但不一定马上处理 | 在当天安排时间 |
| 敲门 | 重要风险、持续挤压或需要明确回应的事项 | 尽快打开查看并处理 |

通知中心会显示未读通知；点击通知可将其标记为已读。已读通知可以展开查看历史。

## 6.4 敲门通知声音

如果希望收到“敲门”通知时播放提示音：

1. 打开左侧“设置”。
2. 进入“数据与隐私”或通知相关设置区域。
3. 打开“敲门通知声音”。
4. 发送测试提醒或等待下一次敲门通知。

默认建议保持关闭，避免在会议或安静环境中产生打扰。

## 6.5 晨间简报

晨间简报用于开始一天前快速了解：

- 重要任务和临近截止事项；
- 本周大石头；
- 角色状态和需要关注的风险；
- 今日建议的重点安排。

查看方式：

1. 在管家对话中打开生成的晨间简报；或
2. 等待配置的自动生成时间；或
3. 在设置中手动触发（如果当前版本提供该入口）。

阅读简报时，建议只选出 1～3 个当天真正要推进的重点。

## 6.6 配置节奏时间

打开“设置” → “调度时间”：

- 配置晨间简报时间；
- 配置周复盘时间；
- 配置大石头规划提醒时间；
- 根据需要启用或关闭对应节奏。

修改后保存，并确保应用在需要运行的时间段能够正常启动。

> [截图占位：全局设置的“调度时间”页面。应展示晨间简报、周复盘和大石头规划的时间配置。]

## 6.7 规划本周大石头

每周开始时，管家可能提醒你规划本周重点：

1. 打开“规划下周大石头”或类似入口。
2. 阅读每个角色给出的建议。
3. 接受、编辑或删除建议。
4. 手动补充缺少的重点任务。
5. 保存本周计划。

计划完成后，任务会在对应角色的任务列表中突出显示。

## 6.8 周复盘

周复盘会汇总一周的任务完成情况、角色能量趋势和大石头进展，并以正向叙事的方式帮助你回顾。

1. 打开管家视图中的周复盘入口。
2. 阅读本周摘要。
3. 查看角色能量趋势。
4. 检查大石头完成、延期或未开始的原因。
5. 点击“规划下周大石头”进入下一周计划。

复盘的重点不是给自己打分，而是找出下一周应保留、停止或调整的做法。

> [截图占位：周复盘弹窗。应展示本周摘要、能量趋势、大石头列表和进入下周规划的按钮。]

## 6.9 大石头保护提醒

工作日中，如果大石头持续没有进展，管家可能提醒你：

- 把任务拆小；
- 预留时间块；
- 暂停低优先级事项；
- 调整任务范围或重新确认它是否仍是重点。

收到提醒后，最好立即做出一个具体计划，而不是仅点击已读。
