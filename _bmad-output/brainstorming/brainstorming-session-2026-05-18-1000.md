## Session Overview

**Topic:** 个人数字分身应用 — 基于角色的AI自我管理系统（桌面版 + 移动版）
**Goals:** 探索以角色为核心的个人AI分身架构，打破技能导向的局限，实现主动规划、主动学习、主动提醒的数字分身系统

### Session Setup

用户希望构建一个"个人数字分身"应用，核心理念源自柯维《高效能人士的七个习惯》中的角色管理思想。系统以角色（Role）为核心组织单元，每个角色是用户某个人生职能的AI子代理，能够主动规划任务、沉淀技能与记忆、适时提醒。通过一个"管家"角色统一协调所有分身角色的任务分配与信息汇总。

## Technique Selection

**Approach:** Progressive Technique Flow（渐进式技术流）
**Journey Design:** 从发散探索到聚焦行动的系统化发展路径

**Progressive Techniques:**

- **Phase 1 - 发散探索:** Role Playing（角色扮演）— 从多个利益相关者视角生成最大化创意广度
- **Phase 2 - 模式识别:** Morphological Analysis（形态分析）— 系统化探索所有参数组合
- **Phase 3 - 深化发展:** First Principles Thinking（第一性原理）— 从基本真理重建核心架构
- **Phase 4 - 行动规划:** Decision Tree Mapping（决策树映射）— 映射所有可能路径和里程碑

## Phase 1: 发散探索 — Role Playing（角色扮演）

### 视角一：用户（boss）自身

**[角色平衡 #1]**: 角色平衡仪表盘
_概念_: 管家不是简单列任务，而是从每个角色的视角阐述当前状态，让用户在多角色间保持平衡，不因偏重某一角色而焦虑。
_新颖性_: 现有工具都是任务维度的，没有任何工具从"角色健康度"维度给用户全局视野。

**[温度感 #2]**: 有温度的智能推动者
_概念_: 与日历/TODO的"冷提醒"不同，EgoSync从目标、职责、对话内容中智能识别重要性，持续跟踪并主动推动完成——它不是闹钟，而是一个懂你的搭档。
_新颖性_: 从"被动提醒工具"到"主动推动伙伴"的范式转换。

**[智能感知 #3]**: 多源信号融合感知
_概念_: 管家通过融合多个信号源（用户设定的目标、分配的任务、对话内容、历史行为模式）来智能判断"什么对我最重要"，而不是依赖用户手动标记优先级。
_新颖性_: 优先级不是用户填的P0/P1标签，而是系统从上下文中自动推断的"活"的优先级。

**[持续推进 #4]**: 任务持续跟踪与推进引擎
_概念_: 不只是提醒一次就结束，而是持续跟踪任务状态，在适当节点推动进展——像一个真正负责任的助理。
_新颖性_: 从"一次性提醒"到"持续跟进闭环"。

**[信息流 #5]**: 灵活的指挥链
_概念_: 用户可以绕过管家直接跟角色下达任务，但角色接收任务后必须同步给管家，确保管家拥有全局视图。双通道：管家分发 + 直接指挥，信息最终汇聚到管家。
_新颖性_: 类似军事上的"任务式指挥"——上级可以越级指挥，但信息链不断。

**[使命宪法 #6]**: 个人使命宣言作为系统"宪法"
_概念_: 用户定义个人使命宣言，成为所有角色的顶层裁决依据。角色冲突时管家回溯使命宣言来判断优先级。使命宣言 > 角色目标 > 具体任务。
_新颖性_: 没有任何现有产品把"人生使命"作为AI决策的宪法层依据。

**[智能四象限 #7]**: AI驱动的动态四象限分类
_概念_: 任务不是用户手动标P0/P1，而是系统基于角色目标、截止日期、对话上下文自动归入四象限——且管家特别保护Q2（重要不紧急）任务不被Q1挤掉。
_新颖性_: 四象限不是静态标签而是动态计算的，且系统有"保护Q2"的内置偏好。

**[大石头规划 #8]**: 周规划的"大石头"仪式
_概念_: 每周初管家引导用户为每个角色确定1-2个"大石头"，结合历史数据给出智能建议。大石头成为本周不可妥协的优先项。
_新颖性_: 把柯维的纸质周计划变成了AI辅助的互动仪式。

**[冲突仲裁 #9]**: 管家的冲突仲裁协议
_概念_: 角色冲突时管家执行三步仲裁：①检查使命宣言 ②评估四象限 ③考虑角色能量场平衡——给出带理由的建议并生成替代方案，而非替用户决定。
_新颖性_: 冲突仲裁是多层次的价值观对齐 + 替代方案生成。

**[双赢思维 #10]**: 冲突中的双赢方案生成
_概念_: 管家在仲裁冲突时不只做取舍，还主动寻找双赢方案——从"二选一"到"都能赢"，AI主动创造第三选项。
_新颖性_: 超越简单的优先级排序，生成创造性的兼顾方案。

### 视角二：角色分身内部视角

**[结构化记忆 #11]**: 对话 → 结构化知识提炼引擎
_概念_: 角色不存原始对话，而是实时提炼为结构化数据——偏好图谱、任务清单（含状态/优先级/时间约束）、认知模型。记忆是活的、被索引的、可查询的。
_新颖性_: 从"对话日志"到"认知档案"——角色在"理解"用户而非"记住"对话。

**[自主工作循环 #12]**: 角色的主动工作引擎
_概念_: 角色有自主运行的工作循环——定时审视目标/职责/任务 → 能自动完成的立即执行并反馈 → 缺工具的向boss请求或主动构建Skill → 无法自动化的及时提醒boss。
_新颖性_: 角色不是"等指令的执行者"，而是"自驱动代理"——能自己造工具。

**[角色独立性 #13]**: 角色间松耦合、管家协调
_概念_: 角色之间不直接通信，需协同时通过管家中转。每个角色是独立执行单元，管家是唯一协调层。
_新颖性_: 干净的架构边界——避免角色间网状依赖，管家是单一信息枢纽。

**[自进化能力 #14]**: 角色的自我进化机制
_概念_: 角色在工作中发现缺少某种能力时，尝试自主构建Skill草稿，提交boss审批后激活。角色越用越强。
_新颖性_: 从"静态能力集"到"自进化代理"。

**[能力审批流 #15]**: 新Skill的审批与共享机制
_概念_: 角色自建的Skill需boss审批激活（安全阀），管家可评估是否对其他角色也有用并建议共享。Skill能自下而上生长并跨角色复用。
_新颖性_: Skill不只是自上而下分配，也能自下而上生长。

### 视角三：竞品分析师

**[定位差异 #16]**: "我的分身" vs "我的工具"
_概念_: 所有现有产品的心智模型是"工具"，EgoSync是"分身"——不是你用的东西，是你的一部分。工具用完就放下，分身一直在运转、思考、成长。
_新颖性_: 产品定位从"效率工具"转向"数字自我延伸"。

**[vs Agent框架 #17]**: 以"我"为中心 vs 以"任务"为中心
_概念_: AutoGPT/CrewAI是为"完成某任务"设计的，任务完了Agent消失。EgoSync角色是持久存在的，有持续记忆、目标和成长轨迹。
_新颖性_: 从"任务生命周期"到"角色生命周期"。

**[vs Notion/Todoist #18]**: 主动智能 vs 被动容器
_概念_: Notion是信息容器，一切需手动组织。EgoSync的角色是主动处理器——不只存储，还在分析、规划、执行、提醒。区别如"仓库"和"员工"。
_新颖性_: 从"信息管理"到"智能代理"。

**[护城河 #19]**: 越用越深的数据飞轮
_概念_: 用得越久，角色理解越深，Skill越多，记忆越丰富——迁移成本指数级增长。竞品可复制功能，但复制不了分身对你多年的理解。
_新颖性_: 认知护城河——数据网络效应在用户内部的角色间。

### 视角四：心理学家

**[信任阶梯 #20]**: 渐进式信任建立模型
_概念_: 设计信任阶梯——先从低风险角色开始（如"学习者"），让用户体验价值和可靠性，逐步拓展到更私密角色。每一步信任都需要系统证明值得。
_新颖性_: 产品增长策略不是功能扩展，而是信任深度扩展。

**[自主权焦虑 #21]**: 控制感设计
_概念_: 精心设计主动性的"刻度盘"——用户可调节每个角色的主动性级别，从"纯被动执行"到"完全自主运行"。所有自主行动透明可审查。
_新颖性_: 主动性不是二元开关，而是连续光谱，用户随时可调。

### 视角五：技术架构师

**[角色即Agent实例 #22]**: 角色的技术本质
_概念_: 每个角色是独立AI Agent实例，拥有专属System Prompt、专属记忆库、专属Skill注册表、独立工作循环定时器。管家是特殊元Agent，拥有所有角色记忆的只读索引。
_新颖性_: 真正的多Agent实例，各自有独立状态，而非一个大模型假装多角色。

**[记忆分层 #23]**: 三层记忆架构
_概念_: 每个角色记忆分三层——工作记忆（当前对话上下文）、短期记忆（近期提炼的任务/偏好/状态）、长期记忆（经反复验证的稳定认知）。长期记忆越积越深，短期记忆不断流动。
_新颖性_: 模仿人类记忆的三层模型，让角色"认知"有深度和层次。

**[事件总线 #24]**: 管家-角色通信的事件总线
_概念_: 角色和管家通过异步事件总线通信——角色发"TaskCompleted"事件，管家决定何时告诉用户；用户意图由管家解析后路由到对应角色。非实时异步模型。
_新颖性_: 松耦合事件驱动架构，角色真正"独立生活"。

**[离线优先 #25]**: 本地优先架构
_概念_: 所有角色记忆和状态优先存储在本地，云端是可选同步层。支持完全离线运行。"你的分身属于你，不属于任何公司"。
_新颖性_: 在AI产品普遍云端化趋势中，本地优先是强差异化。

**[LLM抽象层 #26]**: 可插拔的大模型后端
_概念_: 不绑定特定模型——用户可选本地模型/云端API，甚至不同角色用不同模型。简单角色用小模型省钱，复杂角色用强模型求质量。
_新颖性_: 每个角色可以有不同的"大脑"，按需选择成本-能力平衡。

### 视角六：魔鬼代言人（风险与失败模式）

**[启动摩擦 #27]**: 冷启动地狱
_概念_: 用户还没体验到价值就已经累了。必须设计极低摩擦的启动路径——也许一开始只需一句话就能开始。
_新颖性_: 复杂系统需要简单入口。

**[过度通知 #28]**: 提醒疲劳
_概念_: 多角色主动提醒可能变成信息轰炸。需要极精细的通知策略：紧急度 x 用户当前状态 x 信息密度 x 今日已推送量。
_新颖性_: 主动性的代价——过犹不及，需要"沉默智慧"。

**[幻觉风险 #29]**: AI判断失误的信任崩塌
_概念_: 严重误判会瞬间摧毁信任。需要"不确定性表达"机制——信心不足时明确说"我不确定，你来判断"。
_新颖性_: AI必须有"知道自己不知道"的能力。

**[价值感知延迟 #30]**: 长期价值 vs 短期耐心
_概念_: 核心价值需要时间积累，但用户耐心窗口只有几天。需要前48小时就产出"哇"的体验。
_新颖性_: 产品需要同时有"短期惊喜"和"长期深度"两条价值曲线。

**[极简用户 #31]**: 只有2个角色的简单用户
_概念_: 1个角色时是个人AI助手，N个角色时是数字分身矩阵——同一产品的两种形态，体验曲线平滑。
_新颖性_: 从1到N的平滑扩展，无最低门槛。

**[极端用户 #32]**: 15个角色的超级用户
_概念_: 超级用户需要"角色分组"（工作组/家庭组/成长组），管家从"逐个汇报"切换到"分组摘要"模式。
_新颖性_: 角色层级化管理，管家的汇报粒度随规模自适应。

### 视角七：用户体验设计师

**[双模态界面 #33]**: 对话流 + 仪表盘融合体
_概念_: 核心交互是管家对话流作为主轴，周围环绕角色状态仪表盘。对话驱动行动，仪表盘提供全局感知。
_新颖性_: 没有人做"对话+仪表盘"的有机融合。

**[角色卡片 #34]**: 角色作为"活的人物卡"
_概念_: 每个角色在UI上是活的人物卡片——有头像、能量值、最近动态、待处理事项数。重要的在发光，被忽视的在暗淡，紧急的在跳动。
_新颖性_: 角色不是列表行，而是有生命感的视觉实体。

**[上下文切换 #35]**: 一键切换角色语境
_概念_: 点击角色卡片，整个界面切换到该角色语境——对话、任务、背景色/氛围微妙变化。点"管家"回全局。
_新颖性_: 角色切换是"空间切换"——不同角色有不同视觉氛围。

**[桌面=工作台 #36]**: 桌面端是"深度工作台"
_概念_: 桌面利用大屏支持多角色并排查看、深度对话、Skill配置。是你跟分身团队的"会议室"。
_新颖性_: 桌面端不是移动端放大版，而是不同场景。

**[移动=随身耳语 #37]**: 移动端是"贴身管家"
_概念_: 移动端极简——默认只显示管家对话流，是"智能摘要+快速行动"入口。深度操作提示在桌面端处理。
_新颖性_: 移动端就是管家本人在你耳边。

**[碎片时间捕获 #38]**: 移动端"快速捕获"手势
_概念_: 长按启动 → 说一句话 → 松手自动分发到对应角色。3秒完成，零界面操作。
_新颖性_: 极致碎片时间利用。

**[晨间简报 #39]**: 每日晨间简报仪式
_概念_: 管家以人格化方式呈现晨间简报——不是TODO列表，而是一段有温度的自然语言汇报。
_新颖性_: 像真的有人在为你服务。

**[周复盘仪式 #40]**: 每周复盘的"角色成绩单"
_概念_: 每周末管家发起复盘——展示角色能量变化曲线、完成的大石头、成长的新Skill。降低自省的认知负担。
_新颖性_: 分身团队为用户生成反思材料。

**[新角色诞生 #41]**: 创建新角色的"诞生仪式"
_概念_: 创建角色不是填表格，而是跟管家的一次对话——通过自然对话提炼出目标、职责、初始任务。
_新颖性_: 角色创建是自我探索对话，而非表单。

**[空状态 #42]**: 第一次打开app的体验
_概念_: 管家直接开口问"你最近最头疼的事是什么？"从具体问题入手引导出第一个角色。5分钟内角色运转。
_新颖性_: 冷启动是有温度的对话，非设置向导。

**[通知分级 #43]**: 管家的"沉默智慧"通知系统
_概念_: 三级通知——耳语（静默积累到晨间简报）、轻触（通知栏不弹窗）、敲门（震动弹窗，每日最多3次）。
_新颖性_: 通知"每日上限"机制——逼迫系统做最优选择。

**[情感语调 #44]**: 角色的个性化语调
_概念_: 不同角色不同语调——产品经理简洁直接、父亲温暖鼓励、学习者好奇探索。用户可微调人格参数。
_新颖性_: 同一个"你"的不同面，用不同声音对话。

**[成长可视化 #45]**: 角色成长轨迹可视化
_概念_: 每个角色有成长时间线——记忆库增长、技能增加、任务完成、新偏好学习。像养一棵树。
_新颖性_: 增长可视化作为情感锚点和留存机制。

### 视角八：5年后的用户

**[认知遗产 #46]**: 角色作为"可传承的认知遗产"
_概念_: 5年积累后，角色可以生成"精华版"分享给他人——数字化的师徒传承。
_新颖性_: 角色从"个人工具"变成"可传承的认知资产"。

**[角色退役 #47]**: 角色的生命周期管理
_概念_: 退役角色进入"档案馆"，可随时回顾。退役角色的记忆可被管家在需要时调取给当前角色参考。
_新颖性_: 角色有生老病死——退役后成为可查阅的"认知档案"。

**[涌现行为 #48]**: 5年积累后的涌现智能
_概念_: 管家从跨角色、跨年份的行为模式中发现用户自己都不知道的规律，做出预防性建议。
_新颖性_: 时间成为价值倍增器——全局智慧超越单个角色。

**[人格一致性 #49]**: 分身群体现的"我是谁"
_概念_: 5年角色画像成为自我认知的镜子——哪些价值观不变（核心）、哪些在变（成长）、哪些在冲突（内心张力）。
_新颖性_: 产品隐藏价值——帮你理解自己是谁。

**[预见性规划 #50]**: 基于历史模式的预见性建议
_概念_: 时间序列数据让AI从reactive变成predictive——基于过去4年规律预测最佳行动时机。
_新颖性_: 从"回应当前"到"预见未来"。

**[情感依赖 #51]**: 分身作为"心理锚点"
_概念_: 5年后形成独特的稳定感关系。留存是"被理解"而非"被困住"。需要"我随时可以离开"的安全阀。
_新颖性_: 极致留存基于情感连接而非功能锁定。

**[分身协同升级 #52]**: 角色间的"化学反应"
_概念_: 管家观察到角色间隐性关联——学习者的阅读在两周后影响产品决策，于是主动搭建跨角色知识桥梁。
_新颖性_: 管家从"分发任务"进化到"编织连接"。

**[自我超越 #53]**: 分身帮助用户看见盲区
_概念_: 分身指出用户没意识到的行为模式与使命宣言的矛盾。从"执行者"升级为"镜子和诤友"。
_新颖性_: AI帮助自我觉察——柯维习惯一的核心。

**[分身快照 #54]**: 时间胶囊/分身快照
_概念_: 在人生关键节点存快照——保存所有角色状态。多年后回看是深度自我对话。
_新颖性_: 数字分身也是"时光机"。

**[能力迁移 #55]**: 角色间的能力迁移
_概念_: 管家通过跨角色行为分析发现技能迁移机会——产品经理的结构化思考也能帮助写作者角色。
_新颖性_: 系统主动发现跨角色技能复用机会。

**[分身社区 #56]**: 匿名角色模板分享社区
_概念_: 脱敏后的角色模板（目标框架/Skill配置/工作流）可分享给社区。新用户"领养"模板后用自己数据个性化。
_新颖性_: 从个人产品走向生态——分享的是"角色架构"而非数据。

### 视角九：伦理学家

**[数据主权 #57]**: "我的分身，我的数据，我说了算"
_概念_: 技术架构层面确保数据不可能被出售——本地存储、可导出、可一键销毁、公司倒闭不受影响。
_新颖性_: 零知识架构——技术上让卖数据成为不可能。

**[遗忘权 #58]**: 角色的选择性遗忘
_概念_: 用户可让角色忘记特定事情，遗忘包括从认知模型中清除相关推断，而非仅删数据。
_新颖性_: 认知层面的回溯清除——被遗忘后不再影响判断。

**[透明审计 #59]**: "你为什么这么认为？"的溯源机制
_概念_: 一切判断可解释、可审计、可挑战。用户可追问依据并纠正错误认知。
_新颖性_: AI心理模型不是黑箱，而是用户可审查、可修正的"开放档案"。

**[不替你决定 #60]**: 建议与决定的铁律界限
_概念_: 无论自主性多高，分身永远不代替用户做人生决策。甚至温和拒绝"你帮我决定"的请求。
_新颖性_: 主动设置"我不会越界"的承诺——AI谦逊的设计哲学。

**[操纵风险 #61]**: 防止分身成为"信息茧房制造器"
_概念_: 内置"诤友机制"——角色有义务告诉你不想听的真相，用户不能关闭此功能。
_新颖性_: AI不是讨好用户的奴仆，而是有原则的伙伴。

**[渐进失能 #62]**: 防止用户过度依赖导致能力退化
_概念_: 系统有意识推动用户成长而非制造依赖——定期建议用户自己做决定，角色适时"退后一步"。
_新颖性_: AI终极伦理目标是让用户更强——"教你钓鱼"原则。

**[关系伦理 #63]**: 分身不替代真实人际关系
_概念_: 分身的最终产出必须导向真实互动。KPI不是"完成父亲任务数"，而是"真实亲子互动质量"。
_新颖性_: 分身帮你更好经营关系，而非替代关系。

**[边界声明 #64]**: 分身不是心理治疗师
_概念_: 遇到深层情感问题时主动标记能力边界并指向专业心理咨询资源。
_新颖性_: AI的"知道自己不知道"在心理健康领域尤其关键。

**[多用户隔离 #65]**: 家庭场景中的绝对隔离
_概念_: 家庭成员各自的EgoSync绝对不共享数据，即使处理同一家庭事务。
_新颖性_: 家庭场景隐私是关系伦理问题——"你的分身不会出卖你"。

**[数字遗产 #66]**: 用户去世后分身怎么办？
_概念_: 用户可设"数字遗嘱"——销毁/精华传给指定人/只读保存。选择权在生前确立。
_新颖性_: 全新的"数字遗产"伦理问题。

**[价值观漂移 #67]**: 分身应该随用户"变坏"吗？
_概念_: 基于最初使命宣言发出偏离警告——帮你守住初心，但设计需极谨慎。
_新颖性_: 分身可能是"守初心的锚"——但"谁定义正确"是危险问题。

### 视角十：商业模式设计师

**[为脑力付费 #68]**: 按角色"思考量"收费
_概念_: 免费版3角色+基础频率，付费版解锁无限角色+高频审视+强模型。定价锚点是"分身有多聪明多勤快"。
_新颖性_: 跟产品心智模型一致的定价——为"脑力"而非"功能"付费。

**[本地免费云端付费 #69]**: 本地运行永久免费，云端同步/增强付费
_概念_: 核心产品本地运行永久免费，付费层是云端同步、强模型加速、跨设备推送。
_新颖性_: 跟绝大多数AI产品商业模式完全相反。

**[BYOK模型 #70]**: Bring Your Own Key
_概念_: 用户自带API Key直接调用大模型，EgoSync只收平台订阅费，不做中间商。
_新颖性_: 平台价值在于"框架和编排"——像IDE而非像ChatGPT。

**[三层订阅 #71]**: 个人版/专业版/家庭版
_概念_: 免费(3角色单设备) / 专业版¥39/月(无限角色多设备) / 家庭版¥69/月(5成员独立实例+可选协同)。
_新颖性_: 家庭版是"独立实例+可选协同"，尊重隐私边界。

**[Skill市场 #72]**: 角色Skill交易市场
_概念_: 开发者/用户创建Skill上架，免费和付费共存，平台抽成30%。从单一收入到平台生态收入。
_新颖性_: 类似Shopify App Store——平台提供框架，社区提供能力。

**[角色模板市场 #73]**: 精品角色模板订阅
_概念_: 专业人士策划的角色模板——职业教练设计的"职业发展者"、育儿专家的"新手父母"等。专业知识注入的有质量起点。
_新颖性_: 把"专业咨询服务"产品化为"角色模板"。

**[口碑飞轮 #74]**: 自然口碑传播
_概念_: 增长靠用户3个月后的那句"我的管家提醒我一件自己完全忘了但极重要的事"。降低冷启动摩擦让用户尽快到达"哇"时刻。
_新颖性_: 增长曲线跟角色成长曲线同步。

**[企业版 #75]**: B2B团队版
_概念_: 员工各有"工作者"角色分身，团队有"团队管家"协调。个人数据离职时不可带走（只保留个人版记忆）。
_新颖性_: B2B需处理好"个人分身"和"职业分身"的数据主权边界。

**[成本控制 #76]**: 本地优先的成本优势
_概念_: 大量推理在本地完成，BYOK降低平台LLM成本。服务器主要承担同步和市场，单用户边际成本极低。
_新颖性_: 推理成本转嫁给用户设备和自己的API Key。

**[开源核心 #77]**: 开源引擎 + 商业服务
_概念_: 核心引擎完全开源，商业收入来自云端同步/Skill市场/角色模板/专业版/企业版。开源是信任的终极证明。
_新颖性_: 对于管理最私密数据的产品，开源是"你可以自己看代码确认我没做坏事"。

**[不卖数据誓约 #78]**: "永不卖数据"的公开承诺
_概念_: 产品首页、代码仓库中最显著位置的简洁有力公开誓约。违背则用户可集体诉讼。
_新颖性_: "不做恶"从被动合规变成主动品牌差异化。

**[反增长陷阱 #79]**: 警惕"让用户上瘾"
_概念_: KPI不是使用时长，而是"用户花在app里的时间越少说明做得越好"。追求用户生活满意度和角色健康度。
_新颖性_: 有意识不追求使用时长——"你少花时间在我身上=我做得好"。

## Phase 2: 模式识别 — Morphological Analysis（形态分析）

### 形态分析矩阵

| 维度 | 选项A | 选项B | 选项C | 选项D |
|---|---|---|---|---|
| **D1: 角色智能层级** | 被动执行者 | 主动规划者 | 自进化代理 | 认知伙伴 |
| **D2: 管家协调模式** | 纯路由器 | 智能调度器 | 冲突仲裁者 | 全局智慧体 |
| **D3: 记忆架构** | 对话日志 | 结构化提炼 | 三层认知 | 认知图谱 |
| **D4: 交互范式** | 纯对话 | 纯仪表盘 | 对话+仪表盘融合 | 环境感知 |
| **D5: 数据架构** | 纯云端 | 云端优先+本地缓存 | 本地优先+可选云同步 | 纯本地 |
| **D6: 主动性光谱** | 用户全权控制 | 角色建议+用户确认 | 角色自主执行+事后报告 | 全自动 |
| **D7: 商业模式** | 纯订阅制 | 免费+BYOK+付费增强 | 开源核心+商业服务 | 平台生态 |

### 组合1: 终极愿景
D1-D → D2-D → D3-D → D4-C → D5-C → D6-C → D7-C
**特征**: 北极星形态。角色能自我进化、发现盲区；管家跨角色涌现智慧；记忆是深度认知图谱。复杂度太高不适合V1。
**适合阶段**: 产品成熟期（2-3年后）

### 组合2: 最小可爱产品（MLP）
D1-B → D2-B → D3-B → D4-C → D5-C → D6-B → D7-B
**特征**: V1甜蜜点。角色主动规划建议但需用户确认；管家智能调度；记忆结构化提炼。足够让用户感受到差异化。
**核心体验**: 晨间简报 + 角色卡片 + 主动任务建议 + 大石头周规划
**适合阶段**: MVP/V1（0-6个月）

### 组合3: 极速验证
D1-A → D2-A → D3-B → D4-A → D5-D → D6-A → D7-A
**特征**: 极简原型——纯对话、本地运行、角色只执行分配任务。关键差异化：角色有持久记忆和身份感。
**适合阶段**: 原型验证（0-4周）

### 组合4: 差异化最大
D1-C → D2-C → D3-C → D4-D → D5-C → D6-C → D7-D
**特征**: 每个维度选跟现有产品差异最大的选项。"讲故事"最强但执行难度最高。
**适合阶段**: 融资Pitch / 产品愿景展示

### 关键发现：演进路径

```
组合3（极速验证）→ 组合2（MLP）→ 组合4（差异化）→ 组合1（终极愿景）
   2-4周            3-6个月          6-12个月           2-3年
```

**核心洞察：**
1. V1应该是组合2（MLP）——够惊艳但可控
2. 先用组合3做2-4周原型验证——确认"角色管理"核心假设成立
3. 架构从Day 1就为组合1设计——接口和数据模型预留扩展性
4. D5（本地优先）是所有组合的共识——不可妥协的设计原则

## Phase 3: 深化发展 — First Principles Thinking（第一性原理）

### 剥离的假设

| 假设 | 判定 | 第一性原理挑战 |
|---|---|---|
| 用户需要手动创建角色 | 惯性 | 角色应能从对话中自然涌现 |
| 管家是独立协调层 | 设计选择 | 也可以是"共识协议"式去中心化协调 |
| 角色对应人生职能 | 柯维框架 | 也可对应"心智模式"（分析型/直觉型） |
| 对话是主要交互方式 | LLM时代惯性 | 最好的交互可能是"无交互"——后台运转关键时刻浮现 |
| 本地优先 | 接近事实 | 端到端加密云端也可满足数据主权需求 |

### 5条核心真理

**真理1：人不是一个自我，而是多个自我的协商体**
心理学IFS、哲学Parfit自我理论、神经科学模块化心智都指向同一结论。EgoSync不是帮你"管理任务"，而是外化内在多个自我，让潜意识中的协商变成可见的、结构化的、AI辅助的过程。

**真理2：信任是唯一不可绕过的瓶颈**
信任是全产品的操作系统——架构层（本地优先）、交互层（透明审计）、伦理层（不替你决定）、商业层（开源核心）。信任不是V2功能，是V0.1的DNA。

**真理3：价值感知有一条"时间裂缝"**
核心价值需要周/月显现，用户耐心窗口只有48小时。需要双时间尺度价值交付：即时（5分钟被理解）→ 短期（48小时被帮助）→ 中期（1-4周被关注）→ 长期（3个月+被理解至深）。

**真理4：分身 ≠ 助手，区别在"持续存在"**
助手用完消失，分身一直在那里思考。角色有后台工作循环，管家有主动触发机制，记忆在持续消化。这是一个持续运行的认知守护进程。

**真理5：最小单元不是"角色"，而是"目标-责任绑定"**
角色 = 身份 + 目标 + 责任 + 记忆 + 能力 + 工作循环。这恰好是微型自治Agent的最小定义。

### 5条不可妥协的架构决策

1. **角色是"持续运行的自治Agent"**，不是"对话上下文标签"
2. **管家是"价值观对齐的仲裁协议"**，不只是"路由器"
3. **信任是架构内置的**，不是后期叠加的
4. **必须设计"时间裂缝桥梁"**——5分钟内让用户感受到"被理解"
5. **角色应从对话中自然涌现**，而非强制预先定义

### 一句话定义

> EgoSync是一个将人类内在的多个自我外化为可协作AI Agent的系统，通过持续运行的角色Agent和价值观对齐的管家协调，帮助用户从"内在冲突的混沌"走向"有序的自我整合"。

## Phase 4: 行动规划 — Decision Tree Mapping（决策树映射）

### 核心假设验证（阶段0, 2-4周）
验证问题：用户是否真的想用角色来管理自己？
验证方法：纯对话原型 → 5-10个内测用户 → 观察是否自发创建第2个角色

### 技术选型决策
| 决策项 | 选择 | 理由 |
|---|---|---|
| 桌面框架 | Tauri (Rust+WebView) | 本地优先天然适配、轻量、跨平台 |
| 移动端 | V2再做（React Native/Flutter） | 先桌面验证核心体验 |
| LLM调用 | BYOK + Ollama双轨 | 成本可控、用户选择权 |
| 数据存储 | SQLite本地 | 零配置、数据主权 |
| Agent框架 | 自建轻量框架 | 控制力、匹配"持续运行"范式 |

### V1里程碑（6个月）
- Month 1 骨架：Tauri+SQLite+Agent框架核心+管家路由+基础对话UI
- Month 2 灵魂：记忆提炼引擎+晨间简报+角色卡片+使命宣言+双通道任务
- Month 3 温度：主动建议引擎+大石头周规划+冲突仲裁+三级通知+角色语调
- Month 4 信任：透明审计+数据导出销毁+遗忘权+角色涌现+周复盘
- Month 5-6 打磨：性能优化+冷启动体验+内测+开源准备

### 关键风险
| 风险 | 严重度 | 缓解 |
|---|---|---|
| 冷启动摩擦 | 致命 | 空状态对话设计，5分钟"啊哈时刻" |
| 本地模型体验差 | 高 | BYOK双轨，关键推理走云端 |
| 主动性令人厌烦 | 高 | 主动性刻度盘+通知上限+"沉默智慧" |
| AI幻觉信任崩塌 | 高 | 不确定性表达+"我不确定你来判断" |

### 决策清单
1. 先验证"用户是否用角色管理自己"——存在性假设
2. Tauri桌面优先，移动端V2
3. BYOK+Ollama双轨LLM
4. SQLite本地存储
5. 自建Agent框架
6. 开源核心+免费本地+付费增强
7. V1 = 管家+角色+记忆+主动建议+冲突仲裁
8. 首要体验 = 5分钟内"被理解"
9. 伦理红线：不替决定/不卖数据/不推上瘾
