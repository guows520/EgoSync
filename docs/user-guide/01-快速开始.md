# 1. 快速开始

本章帮助你完成第一次启动、创建第一个角色，并发送第一条消息。

## 1.1 第一次打开应用

首次运行时，EgoSync 会进入引导流程。按照页面提示完成基础设置即可；后续仍可在“设置”中修改模型服务、通知、调度时间和数据选项。

### 建议准备

- 一个可用的大模型服务配置；
- 你希望长期管理的第一个领域，例如工作、学习、家庭或健康；
- 这个领域最重要的长期目标。

## 1.2 创建第一个角色

1. 在引导页填写角色名称，例如“工作助理”“学习教练”或“家庭管家”。
2. 填写角色目标。目标越具体，后续对话和任务建议越容易聚焦。
3. 选择图标。
4. 选择颜色。
5. 确认创建。
6. 在角色确认界面检查名称、目标和外观，确认后进入应用。

角色目标可以在创建后继续修改，不必一次写得完美。

## 1.3 认识主界面

主界面主要分为三部分：

1. **左侧导航栏**：进入管家、切换角色、添加角色、查看通知、切换主题、打开设置。
2. **中央对话区**：与当前的管家或角色交流。
3. **工作区面板**：查看仪表盘、任务、记忆和设置等信息。

点击左侧的管家图标可回到全局视角；点击某个角色图标可进入该角色视角。

## 1.4 发送第一条消息

1. 进入管家或任意角色。
2. 在底部输入框中描述你的目标、问题或下一步行动。
3. 按 Enter 发送；需要换行时使用输入框提供的换行方式。
4. 等待回复完成。Agent 如果需要读取文件、执行命令或使用外部工具，会在消息中显示相应的过程信息。
5. 如果消息中包含任务、计划或可执行建议，可继续确认或调整。

### 推荐的第一句话

> 我这周要完成一份项目方案，请先帮我梳理目标、拆分步骤，并告诉我需要哪些信息。

## 1.5 配置模型服务

如果无法正常对话，先打开左侧“设置” → “模型服务配置”：

1. 添加或编辑一个 LLM Provider 配置。
2. 填写服务名称、接口地址、模型名称和认证信息。
3. 点击连接测试，确认服务可用。
4. 将需要使用的配置设为默认。
5. 返回对话界面重试。

认证信息由应用按本地安全存储方式保存，不应把 API Key 写入聊天内容或导出的 Markdown 报告。

> [截图占位：全局设置的“模型服务配置”页面。应展示 Provider 列表、默认配置标记、添加/编辑和连接测试按钮。]

## 1.6 日常使用的最短路径

- 想表达意图：先找**管家**。
- 已明确领域：直接找对应**角色**。
- 想追踪行动：打开**任务**。
- 想回顾系统记住了什么：打开**记忆**。
- 想查看整体状态：打开**仪表盘**。
- 想修改行为或外部工具：打开**设置**。
