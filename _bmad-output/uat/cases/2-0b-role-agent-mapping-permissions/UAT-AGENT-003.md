# UAT-AGENT-003 归档角色后它不再参与对话，永久删除后彻底消失

## 业务场景
用户清理不再需要的角色：先"归档"——希望它从日常对话中隐退、不再被调用，但记录还在；之后"永久删除"——希望它从系统里彻底消失，不再以任何形式被后台调用。

## 前置条件
- 存在一个专用于本测试的角色（如"临时角色"），且能正常对话

## 测试步骤
1. 对"临时角色"归档
2. 尝试通过管家或角色列表让该角色参与对话，观察它是否已停用
3. 之后对该角色执行永久删除
4. 确认角色列表中不再出现，且无法再被调用

## 预期结果
- 归档后，该角色不再作为可用角色参与对话（被禁用），但用户感知上是"隐退"而非报错
- 永久删除后，角色从列表彻底消失，后台也不再保留其身份配置，不会出现"幽灵角色"仍被调用
- 操作过程不影响其他角色和管家的正常使用
