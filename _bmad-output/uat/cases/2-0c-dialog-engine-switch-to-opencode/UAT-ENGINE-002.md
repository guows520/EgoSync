# UAT-ENGINE-002 高级引擎临时不可用时，自动降级到基础对话并明确告知用户

## 业务场景
万一更强的对话引擎临时挂了，用户也不该被晾在那里收不到任何回应。系统应当自动切回基础对话能力，让用户还能继续聊，同时以管家的语气善意提醒一句"现在是基础模式"，让用户心里有数而不是一头雾水。

## 前置条件
- EgoSync 正常运行
- 具备让高级引擎临时不可用的手段（如强制结束后台引擎进程）

## 测试步骤
1. 先正常对话一轮，确认高级引擎工作
2. 制造高级引擎临时不可用（如强制结束后台引擎进程），并在系统尚未完成自动恢复前
3. 立刻在对话框发送一句话
4. 观察是否仍能得到回复，以及回复中是否有"基础对话模式"之类的友好提示

## 预期结果
- 用户消息不会石沉大海，仍能得到回复（来自基础对话能力）
- 回复中以管家语气清楚告知当前为"Agent 引擎暂时不可用，当前为基础对话模式"之类提示，且只提示一次、不打断正常内容
- 这条用户消息和回复仍被正常保存为历史
- 提示是用户能看懂的自然语言，而非技术错误堆栈
