# 7. 通知、仪表盘与活动统计

## 7.1 打开管家仪表盘

1. 进入管家视图。
2. 打开工作区的“仪表盘”标签。
3. 根据需要设置日期范围和 Agent 筛选条件。

仪表盘用于回答三个问题：最近发生了什么、哪些角色需要关注、哪些任务正在积累风险。

## 7.2 活动统计

活动统计会按所选日期范围汇总跨 Agent 活动。可以使用：

- 日期预设；
- 自定义开始日期和结束日期；
- Agent/归属筛选；
- 全部、管家或角色范围筛选。

查看统计时先确认筛选范围，再比较数字；不同日期范围的指标不能直接混用。

## 7.3 角色状态总览

角色状态总览通常包含：

- 角色名称和颜色；
- 能量值；
- 待办任务数量；
- 最近活跃时间；
- 需要关注的状态提示。

能量值是一个辅助判断指标，不是对人的评价。能量较低可能表示任务积压、近期活跃减少或需要重新安排节奏。

## 7.4 从来源跳转到对话

如果仪表盘、记忆、任务或通知显示了来源信息：

1. 点击来源条目。
2. 系统会切换到对应的管家或角色视图。
3. 对话区会定位到相关消息或上下文。

这可以帮助你从统计数字回到原始语境，避免脱离上下文解读。

## 7.5 通知中心的使用建议

每天可用以下顺序处理通知：

1. 先处理“敲门”通知；
2. 再查看“轻触”通知；
3. 最后批量浏览“耳语”通知；
4. 对已处理通知标记已读；
5. 对重复出现的通知，回到任务或角色设置解决根因。
