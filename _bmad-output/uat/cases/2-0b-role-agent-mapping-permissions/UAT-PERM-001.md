# UAT-PERM-001 把角色的某项能力设为"需确认"后，它执行该操作前会先征询用户

## 业务场景
用户对某个角色不完全放心，希望它在执行像"运行命令""改文件"这类有风险的动作前，先问一下自己，而不是擅自动手。用户把对应权限从"自主执行"改成"需确认"，期望这个边界真的对该角色生效。

## 前置条件
- 存在一个可对话的测试角色
- 该角色当前某项高风险能力为"自主执行"

## 测试步骤
1. 进入该角色权限设置，把某项高风险能力（如执行命令类）从"自主执行"改为"需确认"
2. 保存设置
3. 在对话中引导该角色去做一件会触发该项能力的事
4. 观察该角色在真正执行前是否先向用户征询确认，而不是直接执行

## 预期结果
- 权限修改保存成功
- 该角色在触发受限能力时会先停下来征询用户确认（"需确认"边界生效）
- 用户拒绝时，操作不被执行；用户同意时才继续
- 该权限边界只作用于被设置的角色，不影响其他角色
