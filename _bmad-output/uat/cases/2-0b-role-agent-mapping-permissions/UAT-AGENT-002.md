# UAT-AGENT-002 修改角色的目标/设定后，它的回答风格会随之改变

## 业务场景
用户用着用着发现"产品经理"角色更需要偏向数据分析，于是修改了它的目标描述。用户期望改完保存后，这个角色后续的回答确实按新设定来，而不是还停留在旧的样子。

## 前置条件
- 已存在一个可对话的"产品经理"角色
- 先用旧设定对话一轮，记下它当前的风格

## 测试步骤
1. 进入"产品经理"角色设置，把目标改为更具体的方向，如"用数据驱动的方式评估产品决策，回答时多给量化指标"
2. 保存修改
3. 回到该角色对话区，发送一句与产品决策相关的问题
4. 对比修改前后，回答风格/侧重点是否发生了符合新设定的变化

## 预期结果
- 修改保存成功
- 后续对话明显体现新设定（更偏数据/量化），说明角色身份配置已实时生效
- 修改过程不影响该角色已有的历史对话记录
