# UAT-SIDECAR-004 即使高级对话引擎无法启动，应用也不会打不开、基础对话仍可用

## 业务场景
高级对话引擎是"增强能力"，不是应用能否打开的硬门槛。万一引擎因环境问题没能起来，用户也不能被挡在门外——应用应当照常打开，基础对话功能依旧可用，最多在能力上有所降级。

## 前置条件
- 构造一个对话引擎无法启动的环境（见物料要求）
- 应用此前完全关闭

## 测试步骤
1. 在引擎不可用的环境下打开 EgoSync
2. 观察应用是否能正常打开到主界面（而不是卡在启动或直接报错退出）
3. 在管家对话框发送一句话
4. 观察是否仍能得到回复（哪怕是基础对话模式的回复）

## 预期结果
- 应用正常打开主界面，不因引擎缺失而崩溃或拒绝启动
- 仍可进行基础对话，用户得到回复
- 如有能力降级，应用以可理解的方式提示，而非抛出技术性错误堆栈
