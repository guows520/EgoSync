# UAT 测试用例：Story 1-1 到 2-13

生成日期：2026-06-13  
适用范围：`_bmad-output/implementation-artifacts/1-1` 到 `2-13` 的业务验收测试。  
执行方式：人工端到端验收。所有用例均使用业务语言描述，实际结果和测试结论由执行人现场填写。

## 通用测试数据与环境约定

- 应用：EgoSync Tauri 桌面应用，使用当前待验收构建。
- LLM Provider：至少准备 1 个可正常对话的测试 Provider；另准备 1 个无效 Key 或断网环境用于失败场景。
- 测试角色：
  - `产品教练`：图标 `🧭`，颜色蓝色，目标“把模糊想法拆成可执行计划”。
  - `健康教练`：图标 `🏃`，颜色绿色，目标“帮助用户制定健康习惯和训练计划”。
  - `家庭助理`：图标 `🏠`，颜色橙色，目标“帮助用户安排家庭事务”。
  - `写作顾问`：图标 `✍️`，颜色紫色，目标“帮助用户写作和总结”。
- 测试账号状态可按用例要求清空或预置；涉及“首次打开”的用例需使用全新用户数据目录。
- 涉及 Skill 的用例，准备：
  - 合法 `SKILL.md`：名称 `meeting-action-extractor`，说明“将会议纪要整理为行动项”。
  - 无效 `SKILL.md`：缺少必填名称或说明。
- 涉及 MCP 的用例，准备一个可用的测试 MCP server，例如 `uat-weather-mcp`；并准备一个故障 server 配置用于失败场景。

- 每个用例执行后，在“实际结果”记录观察到的页面表现、提示文案或数据变化。
