# 1. 快速开始

本章帮助你完成第一次启动、创建第一个角色，并发送第一条消息。

## 1.1 第一次打开应用

首次运行时，EgoSync 会进入引导流程，引导你配置称呼和第一个角色。按照页面提示完成基础设置即可；后续仍可在“设置”中修改模型服务、通知、调度时间和数据选项。

### 建议准备

- 一个可用的大模型服务配置；
- 你希望长期管理的第一个领域，例如工作、学习、家庭或健康；
- 这个领域最重要的长期目标。

## 1.2 配置模型服务

1. 单击“配置大模型服务” 按钮，进入“模型服务配置”页面

![[1.2.1.png]]

2. 单击 “+ 添加新配置” 进入配置页面

![[1.2.2.png]]

3. 配置模型服务信息

![[1.2.3.png]]

4. 单击“测试链接” 看大模型服务是否可以连接成功

![[1.2.4.png]]

## 1.3 配置你的称呼

关闭模型服务配置，进入主页面后，引导流程首先会引导你配置称呼

如果你暂时不想设置，可以直接点击右下角的“跳过角色引导”按钮，跳过整个引导过程，后续仍然可以在“数字分身管家”的配置页面，手工进行配置

![[1.3.1.png]]

## 1.4 创建第一个角色

1. 引导流程会引导你创建第一个角色，你直接描述角色名称和角色目标即可

![[1.4.1.png]]

2. EgoSync会自动识别你的输入，然后弹出角色配置页面让你确认

![[1.4.2.png]]

3. 单击“创建”按钮，即可完成角色创建

![[1.4.3.png]]


4. 你也可以直接通过单击左侧导航栏的“添加角色”按钮，手动完成角色创建

## 1.5 认识主界面

主界面主要分为三部分：

1. **左侧导航栏**：进入管家、切换角色、添加角色、查看通知、切换主题、打开设置。
2. **中央对话区**：与当前的管家或角色交流。
3. **工作区面板**：查看仪表盘、任务、记忆和设置等信息。

点击左侧的管家图标可回到全局视角；点击某个角色图标可进入该角色视角。

![[1.5.1.png]]

## 1.6 发送第一条消息

1. 进入管家或任意角色。
2. 在底部输入框中描述你的任务、问题或要求。
3. 按 Enter 发送；需要换行时使用输入框提供的换行方式。
4. 等待回复完成。Agent 如果需要读取文件、执行命令或使用外部工具，会在消息中显示相应的过程信息。
5. 如果消息中包含任务、计划或可执行建议，可继续确认或调整。

## 1.7 日常使用的最短路径

- 想表达意图：先找**管家**。
- 已明确领域：直接找对应**角色**。
- 想追踪行动：打开**任务**。
- 想回顾系统记住了什么：打开**记忆**。
- 想查看整体状态：打开**仪表盘**。
- 想修改行为或外部工具：打开**设置**。
