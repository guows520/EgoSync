# UAT-ENGINE-003 回复进行到一半时点停止，能立即叫停并恢复输入

## 业务场景
用户发现管家正在长篇大论或方向跑偏，想中途喊停。点了停止按钮就应当立刻让它住口，并且输入框马上恢复可用，让用户能重新发问，而不是卡在"正在回复"的状态里动弹不得。

## 前置条件
- EgoSync 正常运行，高级引擎可用
- 当前对话空闲、输入框可用

## 测试步骤
1. 发送一个会引发较长回复的请求，如"详细介绍一下个人知识管理的完整方法论"
2. 在回复流式输出过程中，点击停止按钮
3. 观察回复是否立即停止继续输出
4. 观察输入框/发送按钮是否随即恢复，可以马上发下一条消息
5. 发送下一条消息确认对话正常继续

## 预期结果
- 点击停止后，正在生成的回复立即停止，不再继续吐字
- 后台对应的执行被中断（不会偷偷在后台跑完）
- 界面随即恢复到可输入状态，用户能立刻发新消息
- 已经输出的部分内容被正常保留，不影响后续对话
