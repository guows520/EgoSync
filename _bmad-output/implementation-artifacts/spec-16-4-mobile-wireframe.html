四个搬迁控件的新家（对应你选的方案 A）

🔔 通知铃铛 → 管家视图头部右上角（今天有什么新建议一眼可见），角标保留；
🟢 连接状态 → 管家视图头部（在线/重连中三态小圆点，断线时接管为横幅）；
🌗 主题切换 → 设置页首屏（浅色/深色一行切换，替代侧栏按钮）；
🚪 登出 → 设置页底部「账号」区（带确认，防误触）。

移动端设置 = 桌面设置的全量（除桌面专属）

设置 tab 列出的每一项打开的就是桌面 GlobalSettingsModal 的同款内容（同一批组件，不重写）：模型服务（LLM Provider）、MCP Server、调度时间、数据与隐私（导出/导入/销毁）、通知、主题、登出。桌面专属的「远程模式 / 手机伴侣」在浏览器宿主下由 capabilities 门控自动不显示；角色级设置（角色信息/主动性/技能/MCP）仍在角色详情内的「设置」tab，与桌面结构一致。

角色 tab 交互规则（回答你的三个问题）

① 点「角色」tab 默认看到啥：角色列表（第一级）——管家固定第一行+各角色一行+右上「＋」。
② 怎么切换：列表里点另一个角色 → 直接进它的详情并成为当前；在第二级时再点一次底部「角色」tab（标准 tab 行为：点已选中的 tab 回该 tab 的根）→ 回列表再选。
③ 第二级怎么新增角色：角色详情页头部「⋯」菜单 = 「切换角色 / 新建角色」直达（见图 2b 弹出的菜单），不用先回列表。

保持不变的部分

底部 tab 固定三个（管家/角色/设置，UX 初案不动，tab 数量/位置属结构变更需你批准）；管家视图内的「仪表盘/任务/记忆/设置」既有顶部 tab 保留；输入框与发送按钮 44×44px 贴底；底部横线区域为 iPhone 安全区避让位。
