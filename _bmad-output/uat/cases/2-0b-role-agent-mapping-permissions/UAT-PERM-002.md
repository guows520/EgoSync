# UAT-PERM-002 管家始终是总管且权限最高，重启后所有角色身份与用户数据保持一致

## 业务场景
管家是用户的总入口和总协调者，应当始终在线、拥有最高权限去调度各角色。用户也希望无论怎么重启应用，自己当前拥有的角色（含已归档的）在后台的身份配置都和实际看到的一致，不会莫名多出或丢失角色。

## 前置条件
- EgoSync 中已有至少 2 个角色，其中至少 1 个为已归档状态
- 准备重启应用一次

## 测试步骤
1. 记录当前角色列表（含归档状态）
2. 完全退出并重新打开 EgoSync
3. 启动后与管家对话，确认管家正常工作且能协调/提及各角色
4. 检查角色列表是否与重启前一致（数量、归档状态都对得上）
5. 切换到各活跃角色分别发一句话，确认都能正常对话

## 预期结果
- 管家始终可用，作为总管能正常协调各角色
- 重启后角色列表与重启前完全一致，没有凭空多出的"幽灵角色"，也没有该在却消失的角色
- 已归档角色仍处于停用状态，活跃角色均可正常对话
- 用户无需任何手动修复操作，一致性由系统自动维护
