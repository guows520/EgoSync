# UAT-ENGINE-006 对话中途引擎崩溃，用户重试后对话能恢复正常

## 业务场景
用户正在和角色聊得好好的，后台引擎突然崩了。用户最关心的是：我之前聊的还在不在？我还能不能接着聊？理想情况是——稍等片刻系统自动把引擎拉回来，用户重发一句就能继续，历史一条没丢。

## 前置条件
- EgoSync 正常运行，已与某角色进行过一轮对话
- 具备强制结束后台引擎进程的手段

## 测试步骤
1. 在某角色对话中正常完成一轮对话
2. 模拟引擎崩溃：强制结束后台对话引擎进程
3. 等待数秒让系统自动恢复
4. 在同一对话里重新发送一句话
5. 观察对话是否恢复正常，并检查崩溃前的历史是否完整

## 预期结果
- 引擎崩溃不会导致应用窗口崩溃或卡死
- 系统在短时间内自动恢复引擎，用户重试发送后能正常得到回复
- 崩溃前的对话历史完整保留，上下文尽可能延续
- 期间若曾短暂降级，会有可理解的提示，而非技术报错
