# UAT-A11Y-002 交互元素有aria-label与语义化角色

## 业务场景
屏幕阅读器用户希望所有交互元素有可理解的名称（aria-label 或可见文本），流式输出区域有 log 角色，Modal 有 dialog 角色，自己能正确理解界面内容。

## 前置条件
- 应用已启动

## 测试步骤
1. 用屏幕阅读器（如 NVDA/VoiceOver）浏览应用
2. 检查 Sidebar 按钮是否有 aria-label
3. 检查流式输出区域是否有 role="log" aria-live="polite"
4. 打开 Modal 检查是否有 role="dialog" aria-modal="true"
5. 检查通知铃铛是否有 aria-label

## 预期结果
- 所有交互元素有 aria-label 或可见文本名称
- 流式输出区域使用 role="log" aria-live="polite"
- Modal 使用 role="dialog" aria-modal="true" 与可访问标题
- 通知铃铛有 aria-label="有新通知"
- 屏幕阅读器能正确朗读界面内容
