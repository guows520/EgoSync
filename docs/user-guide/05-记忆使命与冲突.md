# 5. 记忆、使命与冲突仲裁

## 5.1 结构化记忆是什么

EgoSync 会从对话中提炼可能长期有用的信息，例如：

- 偏好和习惯；
- 稳定的工作方式；
- 项目背景和约束；
- 重要人物、时间和关系；
- 你对某类事情的长期判断。

记忆不是完整聊天记录，而是可以被角色在后续对话中引用的结构化信息。

## 5.2 查看记忆

1. 进入管家或某个角色。
2. 打开“记忆”标签。
3. 浏览记忆条目、创建时间和来源。
4. 点击某条记忆的来源入口，回到产生该记忆的对话位置。

查看记忆时重点关注：内容是否准确、是否仍然有效、是否属于正确角色。

## 5.3 选择性遗忘

如果某条记忆不再准确或不应继续保留：

1. 在记忆列表找到该条目。
2. 点击删除或遗忘。
3. 确认操作。

选择性遗忘只处理指定记忆，不会自动删除其他任务、对话或角色资料。涉及敏感内容时，应同时检查相关对话和导出文件。

## 5.4 设置个人使命宣言

使命宣言是全局层面的长期方向，帮助管家在多个任务之间做取舍。

1. 打开“设置”或管家设置中的使命区域。
2. 输入你希望长期坚持的方向。
3. 保存。

好的使命宣言不必宏大，但应能用于判断：这件事是否值得投入时间、是否符合你的长期方向。

示例：

> 用可持续的节奏做有长期价值的产品，同时保持对家人和健康的投入。

如果暂时没有使命宣言，管家可以根据你的长期行为和任务偏好推断隐含价值观；推断结果应视为建议，而不是固定事实。

## 5.5 发现时间冲突

当不同角色的任务在同一时间段争夺资源时，系统会提示可能的冲突，例如：

- 两个重要任务安排在同一时间；
- 截止时间相同但所需投入超过可用时间；
- 一个角色的紧急任务持续挤压另一个角色的大石头。

冲突提示出现后，不要只看“哪个更急”，还要考虑使命、影响、可逆性和是否能委派。

## 5.6 三步冲突仲裁

管家会将仲裁过程拆成三个步骤：

1. **识别冲突**：说明涉及哪些角色、任务和资源限制。
2. **对齐优先级**：结合使命、截止时间、重要性和实际容量排序。
3. **生成方案**：给出调整时间、拆分任务、委派或降低范围等可执行方案。

你可以在管家给出的仲裁结果或弹出式仲裁界面中查看每一步，再决定是否采纳。采纳后，系统会按方案更新相关任务或计划；执行前请检查截止时间和任务归属是否正确。


## 5.7 如何提高记忆和仲裁质量

- 在对话中明确说出“这是长期偏好”或“只适用于这次项目”；
- 给任务添加截止时间和期望结果；
- 定期删除已经失效的记忆；
- 保持每个角色的领域边界清晰；
- 在冲突仲裁前先确认真实可用时间，而不是只填理想计划。
