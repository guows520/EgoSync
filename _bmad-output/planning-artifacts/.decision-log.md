## 已定决策

1. **角色间知识传递**：V1 严格隔离，跨角色协同延期至 V2。
2. **使命宣言格式**：自由文本与结构化模板并存，由用户选择。
3. **本地模型记忆提炼**：按用户模型配置执行；可能的准确率影响通过 FR-30 不确定性表达告知。
4. **角色能量值**：采用固定加权多维公式（任务完成率 40%、大石头推进度 30%、互动频率 20%、目标更新活跃度 10%），V1 不开放自定义权重。
5. **工作循环频率**：默认每日 2 次；用户可调为每日 1～4 次；应用未运行时不执行。
6. **四象限分类阈值**：置信度低于 80% 时标记“不确定”并允许用户修正。
7. **跨 OS 流式输出**：保持一致体验，由统一流式渲染层抽象 WebView 差异，QA 覆盖三平台。
8. **LLM Provider**：采用 opencode 原生多 Provider，通过 `opencode.json` 配置，EgoSync 提供配置界面。
9. **Agent 引擎**：采用 opencode sidecar，随 Tauri 安装包分发。
10. **任务执行权限**：可配置；默认自主执行（allow），也支持确认（ask）与禁止（deny）。
11. **Agent 引擎引入时机**：立即作为 Epic 2 基础设施变更引入。

### FR-37～FR-39 专项决策

12. **FR-37 Skill 独立启用**：管家与每个角色分别配置、分别维护 Skill 启用状态；@Skill 选择仅展示当前 Agent 已添加且启用的 Skill，指定 Skill 影响当前任务，不改变长期启用状态。
13. **FR-38 仪表盘统计口径**：对话数量按“对话会话数”统计，不按消息条数；支持管家/角色与时间范围的组合筛选，默认全部时间范围。时间筛选使用任务/记忆的 `created_at` 和对话会话的 `started_at`；待处理任务先按任务 `created_at` 纳入范围，再按查询时未完成状态计数。
14. **FR-39 MCP Server 独立状态**：MCP Server 自身 `enabled` 状态与角色绑定关系分别维护；任一方切换不自动修改另一方，关闭 Server 时不向运行时暴露其工具。
15. **PRD 最终审查与定稿**：2026-07-22 完成 FR-37～FR-39 的需求、范围、决策与假设索引一致性核验；审查结论为通过定稿，后续交由 UX、架构和 Epic/Story 阶段细化。
16. **FR-39 管家绑定补充（扩展条目14）**：管家新增独立的 MCP Server 绑定集合，与各角色绑定互不影响；管家有效集合为“已绑定且 Server 已启用”的交集。关闭 Server 时保留管家既有绑定，重新启用后恢复可用；角色现有 MCP 行为不变。
17. **手机伴侣（Android）立项与形态**（2026-08-25）：移动路线选定伴侣App（否决"独立App+云端引擎"与"纯响应式PWA"，理由见 addendum），仅Android。桌面为唯一事实源，手机为远程视图+指令入口；引擎/工作循环/数据库/keyring留在桌面，中继只加密转发不存储。V1范围＝一档18项核心FR＋二档6项适配FR的移动呈现，新增§4.14 FR-40～43；桌面优先9项FR明确不进手机。原Non-Goals“移动端延期V2”被本决策取代；云中继成为首个服务端组件，部署与成本方案留架构阶段。
18. **伴侣基建定案与FR-42降级**（2026-08-25，架构阶段，详见 architecture.md 手机伴侣增量章节）：基建方案=Kotlin+Compose 原生客户端、自建 Rust 无状态云中继（axum 0.8，Noise XX 端到端加密、扫码配对、NSD 局域网直连、同协议双承载）、单 VPS Docker 部署；快照口径落死（活跃/近期会话各最近200条+本季度简报复盘+未读通知；记忆库不上机；10MB 上限截断明示）；手机指令统一经桌面 companion_dispatch 注入现有 services。**FR-42 正式降级出 V1**：FCM 凭证无法安全分发到用户桌面端，否决中继 FCM 代理（需放宽零知识隐私假设）；V1 仅应用内通知，NotificationDispatch 抽象层保留后续接入位；PRD §4.14/§6.1/§9 已同步修订。
