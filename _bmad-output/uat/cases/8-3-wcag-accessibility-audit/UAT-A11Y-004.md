# UAT-A11Y-004 减少动效偏好时关闭非必要动画

## 业务场景
前庭功能敏感的用户开启了系统的"减少动效"偏好，希望应用关闭呼吸、滑入、淡出、bounce、spin 等非必要动效和过渡，功能不受影响。

## 前置条件
- 系统开启 prefers-reduced-motion: reduce

## 测试步骤
1. 在系统设置中开启"减少动效"
2. 打开应用观察动画
3. 检查角色卡片呼吸动效
4. 检查过渡/淡出/bounce/spin 动效

## 预期结果
- prefers-reduced-motion: reduce 时关闭呼吸、滑入、淡出、bounce、spin 等非必要动效
- 过渡动画关闭
- 功能不受影响（状态变化仍发生，只是无动画）
- 不影响必要的状态反馈
