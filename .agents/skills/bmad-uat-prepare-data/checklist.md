# Prepare UAT Data — Validation Checklist

## 数据契约收集
- [ ] 已读取范围内所有用例的 data_contract
- [ ] 实体需求已跨用例聚合去重
- [ ] 已区分 auto_generatable true/false

## 自动生成
- [ ] 可自动生成项已通过现有 API/脚本在专用 UAT 环境构造
- [ ] write-isolated 用例已创建专属实体并记录标识
- [ ] 已为实体生成快照记录（含重置/清理说明）于 snapshots/

## 用户协作
- [ ] 不可自动生成项已生成数据需求表（含规格、归属用例、路径列）
- [ ] 已告知用户集中数据目录并等待填写

## 校验
- [ ] 完整性：每个契约项都有对应数据，缺失项已列出
- [ ] 可用性：用户文件存在/可读/符合规格；自动实体处于声明状态
- [ ] 一致性：引用实体相互自洽，无脏/矛盾数据
- [ ] 未通过项已列原因与修正建议

## 交接
- [ ] 输出数据就绪汇总（按用例）
- [ ] 全部就绪后提示运行 bmad-uat-run
