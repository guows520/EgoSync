# UI 与角色设置最终改动总结

## 任务与记忆筛选样式

- 管家任务视图的角色筛选逻辑调整为：从“全部”状态点击某个角色时，只选中该角色，其它角色保持未选中。
- 角色任务视图的象限筛选选中态改为浅角色色背景、深角色色文本。
- 角色记忆筛选选中态改为浅角色色背景、深角色色文本。
- 记忆筛选按钮移除选中后的额外聚焦描边，避免首次点击和失焦后的视觉状态不一致。
- 角色任务象限筛选栏压缩按钮间距和内边距，并禁止换行，确保在较窄右侧面板中保持单行显示。

## 任务卡片视觉调整

- 管家与角色任务卡片的截止日期标签改为更低调的灰色边框和灰色文字。
- 管家与角色任务卡片的“大石头”标签改为透明背景、琥珀色边框和文字。
- 管家与角色任务视图的 Q1-Q4 象限标题统一为黑色。
- 管家任务卡片右侧角色标签保持在卡片右侧，并使不同卡片中的角色色圆点在同一竖线上对齐。
- 管家任务卡片右侧角色标签保持垂直居中，文字长度按内容自然展开。

## 对话区与右侧面板布局

- 角色对话区背景调整为与管家对话区一致的半透明白色/深色背景。
- 管家和角色右侧弹出面板宽度由 40% 调整为 35%。
- 管家和角色对话区在右侧面板打开时宽度由 60% 调整为 65%。

## 角色设置页调整

- 角色设置页移除了“危险区域”。
- 角色设置页移除了“归档角色”入口。
- 角色设置页移除了“永久删除”入口。
- 角色设置页内部的归档确认弹窗已移除。
- 角色设置页内部的删除确认弹窗已移除。
- 角色信息编辑、主动性设置、Skill 配置、MCP 配置等其它设置能力保持不变。

## 保持不变的功能

- 左侧角色栏右键归档角色功能保持不变。
- 左侧角色栏右键删除角色功能保持不变。
- 管家设置页中已有归档角色列表和还原入口保持不变。
- 归档、删除、还原对应的后端调用和应用级刷新逻辑保持不变。
