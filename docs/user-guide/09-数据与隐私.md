# 9. 数据与隐私

EgoSync 采用本地优先的数据思路。任务、记忆、对话和角色资料由应用在本地管理；使用外部模型服务时，发送给服务的内容仍应遵守你的组织和个人隐私要求。

## 9.1 导出数据

打开左侧“设置” → “数据与隐私” → “导出数据”。

可选格式：

| 格式 | 适合用途 | 能否用于恢复 |
| --- | --- | --- |
| SQLite 备份 | 完整备份、优先用于恢复 | 可以 |
| JSON | 跨版本迁移、程序处理 | 可以，取决于版本兼容性 |
| Markdown 报告 | 阅读、分享或归档 | 不可以 |

操作步骤：

1. 选择一种或多种格式。
2. 点击导出。
3. 选择保存位置。
4. 等待导出完成。
5. 检查目标目录中是否生成文件。

建议定期保留一份 SQLite 备份，同时保留一份 Markdown 报告用于人工阅读。

## 9.2 导入数据

导入前，系统会自动备份当前数据。

1. 打开“设置” → “数据与隐私” → “导入数据”。
2. 选择 JSON 或 SQLite 存档文件。
3. 检查文件路径和提示信息。
4. 确认导入。
5. 等待应用完成恢复并重新加载数据。

SQLite 导出可能包含多个数据库文件；按照页面提示选择其中任一入口文件即可让应用自动处理相关数据。

导入前请确认：

- 当前数据已经备份；
- 导入文件来自可信来源；
- 你了解导入会覆盖或合并哪些内容；
- 导入后需要重新检查模型服务、Skill 和 MCP 配置。

## 9.3 销毁全部数据

这是不可逆操作，会删除本地的角色、记忆、任务和对话数据。

1. 先导出需要保留的数据。
2. 打开“设置” → “数据与隐私” → “危险区域”。
3. 点击销毁入口。
4. 阅读警告。
5. 输入 `确认销毁`。
6. 点击“确认销毁”。
7. 等待应用回到初始状态。

只有在确认框中输入完整文本后，销毁按钮才会启用。

## 9.4 API Key 和敏感信息

- 不要把 API Key 写进角色目标、任务标题、聊天内容或 Skill 文件。
- 不要把包含密钥的配置文件上传到公共仓库。
- 导出 JSON 或 SQLite 前确认保存位置安全。
- Markdown 报告适合阅读，但仍可能包含对话和任务中的敏感信息。
- 使用远程 LLM 或 MCP 时，先确认数据传输范围和服务方政策。

## 9.5 主题切换

左侧导航栏提供浅色/深色主题切换。主题偏好会保存在本地；如果没有保存过偏好，应用可能跟随系统主题。

主题只改变显示方式，不改变数据、任务或 Agent 行为。

## 9.6 删除单项数据与销毁全部数据的区别

| 操作 | 影响范围 | 是否可恢复 |
| --- | --- | --- |
| 删除一条记忆 | 单条记忆 | 通常不可直接恢复，建议先确认来源 |
| 删除一个任务 | 单个任务 | 通常不可直接恢复 |
| 归档角色 | 暂时隐藏，数据保留 | 可以恢复 |
| 删除角色 | 角色及其关联数据 | 不能依赖界面恢复，建议先导出 |
| 销毁全部数据 | 整个本地数据集 | 不可恢复 |
